# mutineer-benchmarks

Repeatable benchmarks of [mutineer](https://github.com/davidteren/mutineer)
on real open-source apps: runtime, mutants per second, and killed / survived /
no-coverage / errored / declined / unrun counts, recorded per mutineer release.

Work in progress: the harness lives on the `benchmark/fizzy-harness` branch
for now.
